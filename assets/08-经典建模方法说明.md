# 经典建模方法说明文档

## 概述

经典建模方法是数学建模的"地基"。与 01~07 中的现代算法资产不同，本文件汇总**教材体系的经典模型族**，主要依据姜启源《数学模型》11 章体系（初等模型、简单优化、数学规划、微分方程、稳定性、差分方程、离散模型、概率模型、统计回归、马氏链）、微分方程建模讲义与模糊数学讲义整理。

这些方法的特点是：机理清晰、可解释性强、公式稳定，是 CUMCM A 题（连续型）与评价/决策类问题的主要来源。竞赛中常以"经典模型族 + 现代算法改进 + 数据验证"的组合出现。

> 用途说明：建模手在选模型阶段，先判断题目属于"机理型"还是"数据型"。机理型优先查阅本文件的模型族；数据型优先查阅 02-预测类与 05-统计分析资产。每道子问题最多两个独立模型体系，同一物理机制的不同精度展开按一个模型族计数。

## 1. 初等模型与量纲分析

### 算法介绍

初等模型指不借助复杂数学工具、直接从问题机理出发建立的模型，常见于题目的基础小题或用于建立直观认识。

**公平的席位分配（Q 值法）**：三系学生数 $p_1,p_2,p_3$，现有席位 $n_1,n_2,n_3$。按比例分配出现"总体增加一席某方反而减少"的悖论。改进做法：将"一次性分配"转化为"动态分配"——每次把新的一席分给相对不公平度最大的一方。定义

$$
Q_i=\frac{p_i^2}{n_i(n_i+1)},\quad i=1,2,\ldots,k
$$

每次取 $Q_i$ 最大者获得席位。$Q$ 值法满足"公平性公理"，是席位分配问题的标准方法。

**量纲分析与 π 定理**：设物理量 $q_1,\ldots,q_k$ 间有关系 $f(q_1,\ldots,q_k)=0$，其中基本量纲（长度、质量、时间等）个数为 $m$，则存在无量纲量 $\pi_1,\ldots,\pi_{k-m}$ 使

$$
F(\pi_1,\ldots,\pi_{k-m})=0
$$

用无量纲组合代替原物理量，可大幅减少变量、指导实验设计与经验公式拟合（如汽车刹车距离 $d=kv^2$ 由量纲分析给出）。

**经验建模**：对难以机理推导的现象，从数据拟合经验公式，再用量纲分析校核形式（如双层玻璃窗热传导问题：隔热效果取决于间隙与玻璃厚度之比 $l/d$）。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 分配问题 | 席位分配、资源配额 | 离散、需满足公平性公理 |
| 物理现象 | 刹车距离、降落伞、振动 | 有明确物理量纲 |
| 隔热/结构 | 双层玻璃、血管分支 | 几何比例起决定作用 |
| 排队/决策入门 | 椅子放稳、实物交换 | 直观性、需严格推理 |

- 席位分配对比条形图（比例法 vs Q值法）
- 无量纲量关系散点图（拟合经验曲线）
- 几何示意图（双层玻璃截面）

### 代码实现要点

```python
import numpy as np

def q_value_apportion(p, total_seats):
    """Q值法席位分配"""
    n = np.zeros(len(p), dtype=int)
    for _ in range(total_seats):
        Q = p**2 / (n * (n + 1) + 1e-12)
        n[np.argmax(Q)] += 1
    return n
```

```matlab
function n = q_value_apportion(p, total)
% Q值法席位分配
n = zeros(1, length(p));
for k = 1:total
    Q = p.^2 ./ (n.*(n+1) + 1e-12);
    [~, idx] = max(Q);
    n(idx) = n(idx) + 1;
end
end
```

### 算法选择指南

- 席位/配额分配：首选 Q 值法，备选比例法（作对照）。
- 物理现象经验建模：量纲分析定形式 → 最小二乘定系数。
- 小样本、机理清晰问题：初等模型足够，不必上机器学习。

## 2. 静态优化模型（微分法）

### 算法介绍

静态优化问题的最优解是**数**（而非函数），求解关键是根据建模目的确定恰当的目标函数，一般用微分法（求极值点 + 二阶条件）求解。这类模型是 CUMCM 评价类、决策类问题的常用起点。

**存贮模型（经济批量 EOQ）**：配件厂每天需求 $r$ 件，每次生产准备费 $c_1$，单件贮存费 $c_2$。目标为每天总费用最小：

$$
C(T)=\frac{c_1}{T}+\frac{c_2\, r\, T}{2}
$$

最优周期 $T^*=\sqrt{\frac{2c_1}{c_2 r}}$，最优批量 $Q^*=rT^*=\sqrt{\frac{2c_1 r}{c_2}}$。这是最经典的一维静态优化。

**生猪出售时机**：价格 $p(t)=p_0-gt$ 随时间下降，体重 $w(t)=w_0+rt$ 增加，收益 $R(t)=p(t)w(t)$，求 $R'(t)=0$ 得最佳出售时刻。

**森林救火**：损失费用与过火面积成正比、救援费用与消防队员数相关，求使总费用最小的派出人数。

**最优价格与血管分支**：需求函数确定总收益最大的价格；血管分支按能量损耗最小的约束确定分叉角。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 库存/生产 | 经济批量、生产计划 | 费用结构明确 |
| 定价决策 | 最优价格、生猪出售 | 收益函数可导 |
| 资源调度 | 森林救火、时间安排 | 平衡两项相反费用 |
| 生物优化 | 血管分支、蜂窝结构 | 最小能量原理 |

### 可视化图表类型

- 总费用曲线（含最小值标注）
- 收益-时间曲线
- 参数灵敏度曲线（对 $c_1/c_2$ 扫描）

### 代码实现要点

```python
import numpy as np
from scipy.optimize import minimize_scalar

def eoq(c1, c2, r):
    """经济批量：总费用最小化"""
    C = lambda T: c1/T + c2*r*T/2
    T = minimize_scalar(C, bounds=(1e-6, 1e6)).x
    return T, r*T, C(T)
```

### 算法选择指南

- 目标函数可写、决策变量低维：直接用微分法/`scipy.optimize.minimize_scalar`。
- 决策变量高维：转 01-优化资产的规划/启发式算法。
- 有随机需求：转 7. 概率模型（报童问题）。

## 3. 微分方程建模

### 算法介绍

许多实际问题的数学描述归结为微分方程（组）的定解问题。建模步骤：确定状态变量 → 根据机理列方程 → 定初始/边界条件 → 求解或分析性质。

**传染病模型（动态模型经典）**：设 $i(t)$ 为感染比例，$\lambda$ 为日接触率，$\mu$ 为日治愈率。

- SI 模型：$\dfrac{di}{dt}=\lambda i(1-i)$，所有人终将感染。
- SIS 模型：$\dfrac{di}{dt}=\lambda i(1-i)-\mu i$，阈值 $\sigma=\lambda/\mu$；$\sigma>1$ 病可流行。
- SIR 模型（含移除者 $r(t)$，不能二次感染）：

$$
\frac{ds}{dt}=-\lambda s i,\qquad \frac{di}{dt}=\lambda s i-\mu i,\qquad \frac{dr}{dt}=\mu i
$$

以 $\dfrac{di}{ds}=\dfrac{1}{\sigma s}-1$ 的相轨线判断最终感染比例。带潜伏期的 SIR 扩展与隔离策略是竞赛中的常见改进点。

**人口模型**：Malthus 模型 $\dfrac{dx}{dt}=rx$（指数爆炸）；Logistic 模型

$$
\frac{dx}{dt}=rx\left(1-\frac{x}{N}\right)
$$

$N$ 为环境容量，解为 S 形曲线：$x(t)=\dfrac{N}{1+(\frac{N}{x_0}-1)e^{-rt}}$。用于人口、产品销售、生态容量等。

**其他经典**：药物动力学（多室模型）、追击问题（相对运动方程）、单摆/振动（二阶常微分方程）。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 传染病/舆情 | 传播、免疫、隔离策略 | 状态变量为比例/人数 |
| 人口/生态 | 人口预测、种群数量 | S 形增长、环境容量 |
| 物理过程 | 弹簧、电路、热传导 | 牛顿/基尔霍夫定律 |
| 经济动态 | 资本积累、价格调整 | 随时间演化 |

### 可视化图表类型

- 相轨线图（SIR 的 $i$-$s$ 平面）
- 数值解时间曲线（不同参数 $\lambda,\mu$）
- 阈值 $\sigma$ 分界图（流行/消亡区域）

## 4. 稳定性模型

### 算法介绍

稳定性模型的建模目的**不是求 $x(t)$，而是研究时间充分长以后过程的变化趋势**——平衡状态是否稳定。用微分方程稳定性理论（不求解）判断。

**一阶微分方程平衡点稳定性**：对 $\dot x=F(x)$，平衡点 $x_0$ 满足 $F(x_0)=0$。$F'(x_0)<0$ 时 $x_0$ 稳定，$F'(x_0)>0$ 时不稳定。

**捕鱼业的持续收获（产量模型）**：渔场鱼量

$$
\frac{dx}{dt}=F(x)=rx\left(1-\frac{x}{N}\right)-Ex,\quad E\text{ 为捕捞强度}
$$

平衡点 $x_0=N(1-E/r)$。稳定条件 $E<r$。稳定条件下持续产量 $h(E)=E\,N(1-E/r)$，最优捕捞强度 $E^*=r/2$，最大持续产量 $h_{\max}=rN/4$。进一步可扩展为效益模型（考虑单位捕捞成本与渔产品价格）。

**军备竞赛（二维）**：$x'=-\alpha x+ky+g,\ y'=lx-\beta y+h$，平衡点稳定条件 $kl<\alpha\beta$。

**种群的相互竞争/依存/弱肉强食**：Logistic 竞争模型

$$
\frac{dx}{dt}=r_1 x\left(1-\frac{x}{N_1}-\sigma_1\frac{y}{N_2}\right),\quad
\frac{dy}{dt}=r_2 y\left(1-\frac{y}{N_2}-\sigma_2\frac{x}{N_1}\right)
$$

对四个平衡点（$(0,0),(N_1,0),(0,N_2),(x^*,y^*)$）用二维稳定性判据（特征值实部 / 迹-行列式符号）分类，可得到两物种共存、甲胜、乙胜等情形。捕食者-被捕食者模型（Lotka-Volterra）则表现为围绕中心点的周期振荡。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 资源管理 | 渔业、林业持续收获 | 再生资源适度开发 |
| 生态平衡 | 竞争、共存、灭绝 | 二维 Lotka-Volterra |
| 安全分析 | 军备竞赛、威慑 | 线性差分/微分方程 |
| 长期趋势 | 疫病持续、市场稳定 | 只关心终态 |

### 可视化图表类型

- 平衡点及相平面轨迹图（二维）
- 产量-捕捞强度曲线（$h(E)$ 与最优值标注）
- 稳定域图（参数平面内稳定/不稳定分区）

### 代码实现要点

```python
import numpy as np

def fish_yield(r, N):
    """最优捕捞强度与最大持续产量"""
    E = np.linspace(0, r*1.2, 400)
    h = E * N * (1 - E / r)
    imax = np.argmax(h)
    return E[imax], h[imax]   # (E*, h_max) = (r/2, rN/4)
```

```matlab
% 二维稳定性：特征值
A = [-alpha, k; l, -beta];
eig(A)   % 实部均为负 => 平衡点渐近稳定
```

### 算法选择指南

- 只关心长期均衡：稳定性模型最经济，避免求解全过程。
- 关注均衡能否达成（路径）：配合数值求解。
- 多物种相互作用：二维稳定性 + 相图，阈值由特征值实部确定。

## 5. 差分方程模型

### 算法介绍

离散时间建模：当变量按"时段"演化（以天/周/年为单位），用差分方程 $x_{k+1}=f(x_k)$ 描述。

**蛛网模型（市场经济）**：设 $x_k$ 为第 $k$ 时段商品数量、$y_k$ 为价格，需求 $y_k=f(x_k)$（减函数）、供应 $x_{k+1}=h(y_k)$（增函数）。在平衡点 $P_0(x_0,y_0)$ 附近线性化：

$$
x_{k+1}-x_0=-\alpha\beta\,(x_k-x_0)
$$

收敛条件 $\alpha\beta<1$（需求曲线斜率绝对值 $\alpha$ 与供应斜率倒数 $\beta$ 之积小于 1），与蛛网模型的几何收敛一致。政府可通过价格上限等政策使波动收敛。

**差分形式的阻滞增长**：$x_{k+1}-x_k=rx_k(1-x_k/N)$，用于离散种群、销量预测。

**按年龄分组的种群增长（Leslie 矩阵）**：设各年龄组数量 $x^{(k)}$，则有

$$
x^{(k+1)}=L\,x^{(k)},\qquad
L=\begin{bmatrix} f_1 & f_2 & f_3 \\ p_1 & 0 & 0 \\ 0 & p_2 & 0 \end{bmatrix}
$$

种群长期增长率由 $L$ 的主特征值 $\lambda_1$ 决定：$\lambda_1>1$ 增长、$<1$ 衰减，特征向量给出稳定年龄分布。是人口结构预测的标准工具。

**减肥计划**：节食与运动的能量平衡差分模型。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 市场均衡 | 蛛网模型、价格波动 | 供需差分方程 |
| 种群/人口 | 按年龄分组增长 | Leslie 矩阵 |
| 库存/销售 | 离散需求预测 | 时段递推 |
| 消费/健康 | 减肥计划、积累过程 | 简单递推 |

### 可视化图表类型

- 蛛网迭代折线图（收敛/发散）
- Leslie 矩阵特征值随参数变化
- 各年龄组人口堆叠面积图

| 论文/书籍 | 作者 | 年份 | 来源 |

### 代码实现要点

```python
import numpy as np

def leslie(L, x0, years):
    xs = [x0]
    x = x0
    for _ in range(years):
        x = L @ x
        xs.append(x)
    return np.array(xs)

lam1 = max(np.linalg.eigvals(L))  # 长期增长率
```

### 算法选择指南

- 时间离散（自然时段）：差分方程/Leslie 矩阵。
- 时间连续：微分方程。
- 关注长期增长率：直接求 Leslie 矩阵主特征值，无需逐年迭代。

## 6. 离散模型与层次分析法（AHP）

### 算法介绍

离散模型处理决策变量离散、需排序或选优的问题。其中 AHP 是评价类问题的经典骨架（详细原理见 03-评价类资产，本处给建模手需要的方法要点）。

**AHP 核心步骤**：构造层次结构（目标-准则-方案）→ 两两比较建立判断矩阵 $A=(a_{ij})$ → 层次单排序（特征向量法求权重）→ 一致性检验 → 层次总排序。

一致性检验：

$$
\mathrm{CI}=\frac{\lambda_{\max}-n}{n-1},\qquad \mathrm{CR}=\frac{\mathrm{CI}}{\mathrm{RI}}<0.1
$$

其中 RI 为随机一致性指标（$n=1..9$ 时 RI≈0,0,0.58,0.90,1.12,1.24,1.32,1.41,1.45）。CR≥0.1 时需调整判断矩阵。

**循环比赛的名次**：利用比赛的胜负关系构造"竞赛图"，按得分/特征向量给球队排序，处理循环胜负（A>B>C>A）的悖论。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 多准则决策 | 方案选优、权重确定 | 主观判断两两比较 |
| 名次排序 | 循环赛、排名 | 竞赛图/特征向量 |
| 综合评估 | 方案比选、风险排序 | 与 03-评价组合使用 |

### 代码实现要点

```python
import numpy as np

def ahp(A):
    """AHP权重与一致性检验"""
    lam, v = np.linalg.eig(A)
    imax = np.argmax(lam.real)
    w = np.real(v[:, imax]); w = w / w.sum()
    n = A.shape[0]
    CI = (lam[imax].real - n) / (n - 1)
    RI = {3:0.58, 4:0.90, 5:1.12, 6:1.24, 7:1.32, 8:1.41, 9:1.45}.get(n, 0)
    return w, CI, CI/RI   # (权重, CI, CR)，CR<0.1 通过
```

### 算法选择指南

- 指标两两比较有专家经验：AHP/模糊AHP（见 03-评价）。
- 数据充分：改用熵权法客观赋权，AHP 作对照。
- 方案间循环胜负：特征向量排名法优于简单计分。

## 7. 概率模型

### 算法介绍

当需求、服务时间等具有随机性时，建模为概率模型。核心是把随机量与其分布引入费用/收益函数。

**随机存储（报童问题）**：日需求 $r$ 为随机变量（分布密度 $p(r)$），每件进价 $c_1$、售价 $c_2$、退回价 $c_3$，日订购量 $Q$ 使期望利润最大。最优 $Q$ 满足

$$
P\{r<Q\}=\frac{c_2-c_1}{c_2-c_3}
$$

即累计概率等于"单件利润/单件损失比"。是库存决策的经典模板。

**传送带效率**：工人数 $n$、挂钩数 $m$，求空钩期望数（用随机变量与期望化简）。

**随机决策**：用期望收益/期望效用比较方案；可用蒙特卡洛模拟分布（见 06-综合）。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 库存/采购 | 报童问题、缺货损失 | 随机需求 |
| 服务系统 | 排队、传送带 | 随机到达/服务 |
| 决策分析 | 期望收益比较 | 概率已知或可估计 |
| 保险/金融 | 期望赔付、风险 | 损失分布 |

### 可视化图表类型

- 期望收益-订购量曲线（最优 Q 标注）
- 需求分布直方图与累计概率
- 模拟结果的收益分布直方图

### 关键文献

| 论文/书籍 | 作者 | 年份 | 来源 |
|---------|------|------|------|
| 数学模型（第四版）第9章 | 姜启源 | 2011 | 高等教育出版社 |
| 数学建模算法大全 第25章 存贮论 | 司守奎 | 2011 | 国防工业出版社 |

### 代码实现要点

```python
import numpy as np

def newsvendor(c1, c2, c3, demands, probs):
    """报童问题：离散需求下最优订购量"""
    P = np.cumsum(probs)
    ratio = (c2 - c1) / (c2 - c3)
    idx = np.searchsorted(P, ratio)
    return demands[min(idx, len(demands)-1)]
```

### 算法选择指南

- 需求随机、单周期：报童模型（累积概率临界比）。
- 多周期随机库存：动态规划（见 01-优化）。
- 分布未知：历史数据拟合分布 → 蒙特卡洛模拟。

## 8. 统计回归模型

### 算法介绍

数据型建模的基础：用回归描述变量间依赖关系并做推断。

**多元线性回归**：$y=\beta_0+\beta_1x_1+\cdots+\beta_kx_k+\varepsilon$，最小二乘估计 $\hat\beta=(X'X)^{-1}X'y$。检验：$R^2$（拟合优度）、$F$ 检验（整体显著性）、$t$ 检验（单变量显著性）。残差诊断（正态性、等方差、自相关）用于检验模型假设。

**逐步回归**：按显著性自动筛选自变量（前进/后退/双向），解决多重共线性与变量选择，适合变量多、样本中等的情况。

**数据变换**：非线性关系通过对数、指数、倒数变换化为线性（如 Cobb-Douglas 生产函数取对数）。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 因果关系 | 财政收入、销售量预测 | 多个自变量 |
| 变量筛选 | 因素分析、特征选择 | 变量多、需降维 |
| 非线性 | 增长曲线、需求函数 | 可变换线性化 |
| 检验推断 | 显著性、置信区间 | 需统计检验 |

### 可视化图表类型

- 残差图（拟合值 vs 残差）
- 拟合值与实际值散点
- 逐步回归的变量筛选过程图

## 9. 马氏链模型

### 算法介绍

研究对象的状态随机转移、转移概率与历史无关（Markov 性）。核心是转移概率矩阵 $P=(p_{ij})$（行和为 1）与状态向量 $x^{(k+1)}=x^{(k)}P$。

**正则链**：存在 $m$ 使 $P^m$ 全正。正则链有唯一稳定分布 $\pi=(\pi_1,\ldots,\pi_n)$，满足 $\pi P=\pi$，从任意初态收敛到 $\pi$。稳定分布 $=\begin{bmatrix}\pi\\\pi\\\vdots\\\pi\end{bmatrix}$。

**吸收链**：存在吸收状态，转移矩阵可分块

$$
P=\begin{bmatrix} I & 0 \\ R & Q \end{bmatrix}
$$

基本矩阵 $N=(I-Q)^{-1}$，其元素 $n_{ij}$ 为从状态 $i$ 出发进入吸收态 $j$ 前的期望访问次数，从 $i$ 出发被吸收的期望步数为 $N\cdot\mathbf{1}$ 的分量。$R\,N$ 给出各吸收概率。

**应用**：基因遗传（Hardy-Weinberg）、市场占有率演变、服务系统状态、员工流动与培训计划。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 市场/占有率 | 品牌转移、市场份额 | 转移概率可统计 |
| 遗传 | 基因频率演化 | Hardy-Weinberg |
| 服务/可靠性 | 状态转移、吸收时间 | 吸收链 |
| 排队/培训 | 人员流动 | 长期稳态 |

### 可视化图表类型

- 状态转移图（带概率标注）
- 稳定分布随迭代收敛图
- 吸收概率与期望吸收时间

| 论文/书籍 | 作者 | 年份 | 来源 |
|---------|------|------|------|

### 代码实现要点

```python
import numpy as np

def stationary_distribution(P):
    """正则链稳定分布 π: πP=π, 求和为1"""
    n = P.shape[0]
    A = np.vstack([P.T - np.eye(n), np.ones(n)])
    b = np.r_[np.zeros(n), 1.0]
    pi = np.linalg.lstsq(A, b, rcond=None)[0]
    return pi / pi.sum()
```

```matlab

N = inv(eye(m)-Q);                             % 吸收链基本矩阵
```

### 算法选择指南

- 状态离散、无后效性：马氏链。
- 长期稳态：解 $\pi P=\pi$。
- 到达吸收态时间/概率：吸收链 $N=(I-Q)^{-1}$。

## 10. 模糊数学方法

### 算法介绍

模糊数学处理概念边界不清的决策（如"服务质量好"）。核心是把模糊概念用隶属函数量化。

**模糊集合与隶属函数**：对论域 $U$ 上的模糊集 $A$，映射 $\mu_A:U\to[0,1]$ 给出隶属度。常用隶属函数：三角形、梯形、高斯型。

**模糊综合评价**：设指标权重向量 $A=(a_1,\ldots,a_n)$（$\sum a_i=1$），评语隶属矩阵 $R=(r_{ij})_{n\times m}$，综合评价

$$
B=A\circ R,\qquad b_j=\max_i\min_i\{a_i,r_{ij}\}\ (\text{取大取小})
$$

或加权平均型 $b_j=\sum_i a_i r_{ij}$，按最大隶属度原则给出评语。权重可由 AHP/熵权法给定，与 03-评价资产联动。

**模糊聚类/模糊识别**：用模糊相似关系与传递闭包聚类；贴近度用于模式识别。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 综合评价 | 质量、满意度、绩效 | 评语模糊 |
| 聚类 | 数据软分类 | 相似度模糊 |
| 识别 | 图像/模式分类 | 贴近度 |
| 决策 | 多准则综合 | 与 AHP 组合 |

### 可视化图表类型

- 隶属函数曲线（三角/梯形/高斯）
- 综合评价雷达图
- 模糊聚类树状图

### 关键文献

| 论文/书籍 | 作者 | 年份 | 来源 |
|---------|------|------|------|
| Fuzzy Sets | L. A. Zadeh | 1965 | Information and Control |
| 数学模型（第四版）第9章及配套讲义 | 姜启源 | 2011 | 高等教育出版社 |

### 代码实现要点

```python
import numpy as np

def fuzzy_composite(A, R, mode="maxmin"):
    """模糊综合评价：B = A∘R"""
    if mode == "maxmin":
        B = np.max(np.minimum(A[:, None], R), axis=0)
    else:  # 加权平均
        B = A @ R
    return B / B.sum()
```

### 算法选择指南

- 评语模糊、指标分层：模糊综合评价（权重配 AHP/熵权）。
- 隶属函数需依据数据或专家；阈值与论域要写明来源。
