## 1. 线性规划对偶理论

### 算法介绍

对偶理论回答"最优解的经济含义"。标准 LP

$$
\max Z=CX,\quad AX\le b,\ X\ge 0
$$

的对偶问题为 $\min W=b'Y,\ A'Y\ge C',\ Y\ge 0$。核心性质：

- **弱对偶**：对任意可行解 $X,Y$ 有 $CX\le b'Y$。
- **强对偶**：若原问题有最优解，则对偶问题也有最优解且 $Z^*=W^*$。
- **互补松弛**：$X_j>0 \Rightarrow$ 对应对偶约束取等；$Y_i>0 \Rightarrow$ 对应原约束取等。用于验证最优性与解结构。
- **影子价格**：对偶变量 $Y_i$ 是资源 $i$ 每增加一单位的边际贡献，即右端项 $b_i$ 的偏导数 $\partial Z^*/\partial b_i$。是资源定价、瓶颈识别的核心工具。

单纯形法的矩阵描述：典式下检验数 $\sigma=C-C_BB^{-1}A$，对偶解 $Y=C_BB^{-1}$，为灵敏度分析奠定基础。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 资源定价 | 稀缺资源边际价值 | 有可行对偶解 |
| 瓶颈分析 | 产能/资金约束识别 | 影子价格排序 |
| 最优性验证 | 多方案对比 | 互补松弛 |
| 博弈/经济 | 均衡价格 | 对偶结构 |

### 可视化图表类型

- 影子价格条形图（资源边际价值排序）
- 灵敏度区间图（系数变化对最优值影响）
- 原-对偶目标值对比表

- 大规模 LP：直接求解器 + 对偶结果，不需手工推导。

## 2. 灵敏度分析

### 算法介绍

灵敏度分析回答"参数变化时最优解/最优值如何变化"，是竞赛论文"稳健性"部分的常用内容（与 01-优化资产中灵敏度可视化衔接）。

**目标系数 $c_j$ 变化**：保持当前最优基不变时 $c_j$ 的变化范围（Objective Coefficient Ranges）。范围外需重新求解。
**右端项 $b_i$ 变化**：影子价格有效的 $b_i$ 变化区间（RHS Ranges）；区间内 $\partial Z^*/\partial b_i=\text{影子价格}$ 不变，区间外基改变。
**其他**：增加新变量（列检验 $\sigma_j\le 0$ 则当前解仍最优）、增加新约束（检查当前解是否仍可行）、$A$ 中元素变化。

LINGO 求解后在 *Solution Report* 中直接输出 *Objective Coefficient Ranges* 与 *RHS in Ranges*，是竞赛快速得到灵敏度结果的标准做法。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 稳健性分析 | 参数波动下方案是否仍优 | 最优基不变区间 |
| 报价/定价 | 系数区间确定 | 目标系数范围 |
| 资源评估 | 约束增减影响 | RHS 区间 |
| 政策模拟 | 参数扰动 | 多情景重求解 |

### 可视化图表类型

- 最优值随单个参数变化曲线（区间内线性、区间外折点）
- 双参数灵敏度热力图（2D 参数扫描）
- 最优基变化分界图

### 代码实现要点

```python
import numpy as np
from scipy.optimize import linprog

def sensitivity_scan(c, A, b, param_idx, lo, hi, step):
    """对 b[param_idx] 扫描，记录最优值与基"""
    out = []
    for v in np.arange(lo, hi, step):
        b2 = b.copy(); b2[param_idx] = v
        r = linprog(c, A_ub=A, b_ub=b2, bounds=[(0, None)]*len(c))
        out.append((v, r.fun if r.success else np.nan))
    return out
```

## 3. 运输问题

### 算法介绍

运输问题求解把物资从 $m$ 个产地运到 $n$ 个销地、使总运费最小。产销平衡时标准形式

$$
\min \sum_{i=1}^{m}\sum_{j=1}^{n} c_{ij}x_{ij},\quad
\sum_j x_{ij}=a_i,\ \sum_i x_{ij}=b_j,\ x_{ij}\ge 0
$$

**表上作业法**：① 初始方案（西北角法/最小元素法）；② 最优性检验（位势法：$u_i+v_j=c_{ij}$ 求位势，检验数 $\sigma_{ij}=c_{ij}-(u_i+v_j)\ge0$ 最优）；③ 闭回路调整（沿闭回路增减、取最小回路偶数点）。产大于销/销大于产时虚设产地/销地化为平衡问题。

竞赛中可直接用 LP 求解器（linprog/LINGO）得到运输方案，再用位势法检验结果。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 物资调运 | 供应-需求匹配 | 产销平衡 |
| 物流配送 | 仓库-门店 | 单位运费 |
| 指派特例 | 任务-人员（系数矩阵） | 0-1 简化 |

### 可视化图表类型

- 运输流网络图（产地-销地带流量）
- 单位运费热力图 + 最优方案标注
- 总运费随产销变化的灵敏度

### 关键文献

| 论文/书籍 | 作者 | 年份 | 来源 |
|---------|------|------|------|
| 运筹学（第4版）第3章 | 运筹学教材编写组 | 2012 | 清华大学出版社 |
| 数学建模算法大全 第1章 线性规划 | 司守奎 | 2011 | 国防工业出版社 |

### 代码实现要点

```python
import numpy as np
from scipy.optimize import linprog

m, n = a.shape[0], b.shape[0]   # 产地数、销地数
c_flat = c.reshape(-1)          # 目标系数
# 约束：每个产地供给、每个销地需求
Aeq = np.zeros((m+n, m*n))
for i in range(m): Aeq[i, i*n:(i+1)*n] = 1
for j in range(n): Aeq[m+j, j::n] = 1
beq = np.r_[a, b]
res = linprog(c_flat, A_eq=Aeq, b_eq=beq, bounds=[(0, None)]*(m*n))
x = res.x.reshape(m, n)         # 最优运输量矩阵
```

### 算法选择指南

- 小规模标准运输：表上作业法（竞赛演示性好）。
- 大规模/带容量与中转：网络流（04-图论）或直接 LP。
- 产销不平衡：先虚设产地/销地化为平衡。

## 4. 指派问题

### 算法介绍

指派问题：$n$ 项任务指派给 $n$ 个人，每人一项、每项一人，使总费用最小。0-1 规划形式（$x_{ij}\in\{0,1\}$）。

**匈牙利算法（König 方法）**：① 每行减该行最小元；② 每列减该列最小元；③ 用最少数目直线覆盖所有零元素，若直线数 $<n$，在未被覆盖的最小元素处调整（未覆盖行 $-k$，已覆盖列 $+k$）；④ 重复直至能选出 $n$ 个互不同行同列的零元素。可处理"最大化"（系数取负或大 M 变换）与"人数≠任务数"（虚设）。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 任务分配 | 人-机/人-岗 | 一对一匹配 |
| 选址匹配 | 服务-需求点 | 匹配费用矩阵 |
| 排班 | 班次-人员 | 一对一带约束 |

### 可视化图表类型

- 费用矩阵热力图 + 最优匹配连线
- 指派方案甘特图
- 成本随任务数变化

### 关键文献

| 论文/书籍 | 作者 | 年份 | 来源 |
|---------|------|------|------|
| On methods of solving the optimal assignment problem | H. W. Kuhn | 1955 | Naval Research Logistics |
| 运筹学（第4版）第3章 | 运筹学教材编写组 | 2012 | 清华大学出版社 |

### 代码实现要点

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

row_ind, col_ind = linear_sum_assignment(C)   # 匈牙利算法
total = C[row_ind, col_ind].sum()
```

### 算法选择指南

- 标准一对一匹配：`linear_sum_assignment` 一行求解。
- 附加约束（容量、偏好）：0-1 整数规划（`scipy.optimize.milp` / `pulp`）。
- 大规模：线性规划松弛 + 分支定界。

## 5. 下料与切割问题

### 算法介绍

下料/切割问题是一维或多维整数规划的经典应用，也是 CUMCM 高频原型（钢管下料、最优截断切割）。

**一维钢管下料**：19 米原料钢管切割 4/6/8 米各需若干根。先枚举"合理切割模式"（余料小于最短需求），设 $x_i$ 为按模式 $i$ 切割的原料根数：

$$
\min Z=\sum_i x_i \quad (\text{或总余量}),\qquad
\sum_i a_{ji}x_i \ge b_j\ (\text{各规格需求}),\ x_i\in\mathbb{Z}_+
$$

"切割模式不超过 3 种"等管理约束需要加入 0-1 变量或直接枚举限制。目标可为"原料总根数最少"或"总余量最小"，两者结果可不同，应说明选择依据。

**二维截断切割（最优切割次序）**：从一个长方体切出指定小长方体需 6 次切割，水平/垂直单位面积费用不同，且两次不平行垂直切割间有调整费 $e$。核心是**局部最优准则**：两个平行的待切割面，边距大的先加工。由此将 $6!=720$ 种全排列缩减为 $3!\cdot2^3$ 种满足准则的序列（如 90 种），再枚举/动态规划求最小费用。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 一维下料 | 钢管、板材条切 | 模式枚举 + 整数规划 |
| 二维切割 | 板材、玻璃 | 几何 + 排序优化 |
| 三维切割 | 长方体截断 | 切割次序 + 费用 |
| 库存/剪裁 | 布料、卷材 | 余料最小化 |

### 可视化图表类型

- 切割模式组合图（各模式切割根数）
- 切割次序序列图（费用分解）
- 余料/总根数随模式数变化

### 代码实现要点

```python
import numpy as np
from scipy.optimize import milp, LinearConstraint, Bounds
from scipy.sparse import lil_matrix

# 模式矩阵 A（列=模式，行=规格），需求 b，变量 x_i（整数）
A_lp = lil_matrix((len(b), len(modes)))
for j, m in enumerate(modes):
    for k, cnt in enumerate(m):
        A_lp[k, j] = cnt
res = milp(c=np.ones(len(modes)),
           constraints=[LinearConstraint(A_lp, lb=b, ub=np.inf)],
           integrality=np.ones(len(modes)),
           bounds=Bounds(np.zeros(len(modes)), np.inf))
x = np.round(res.x).astype(int)   # 各模式原料根数
```

- 多维/次序问题：先用局部最优准则缩减搜索空间，再枚举/动态规划。

## 6. 目标规划

### 算法介绍

目标规划处理**多目标、有优先级与偏差容忍**的决策。对每个目标引入正负偏差 $d^+_i,d^-_i$：

$$
\text{约束 } f_i(x)+d^-_i-d^+_i=b_i,\quad d^+_i,d^-_i\ge0
$$

按优先因子分层：$P_1$ 级目标（绝对优先）先满足，再依次满足 $P_2,P_3,\ldots$。目标函数是各偏差的加权和：

$$
\min Z=\sum_i P_{k_i}\,(w_i^+ d^+_i + w_i^- d^-_i)
$$

求解可用字典序多目标线性规划（LINGO 直接支持多级目标）。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 多目标决策 | 利润与环保、成本与满意 | 有优先级 |
| 计划编制 | 生产、人员 | 目标可量化偏差 |
| 资源配置 | 多部门兼顾 | 目标分层 |

### 可视化图表类型

- 目标达成度条形图（$d^+_i,d^-_i$）
- 多目标 Pareto 前沿（与 01-多目标优化衔接）

## 7. 排队论

### 算法介绍

排队论研究顾客随机到达、服务设施有限的服务系统。符号 $A/B/c/N$ 表示到达分布/服务分布/服务台数/容量。

**M/M/1 模型**（到达率 $\lambda$、服务率 $\mu$、$\rho=\lambda/\mu<1$）：

- 系统内平均顾客数 $L=\dfrac{\rho}{1-\rho}$，平均排队长度 $L_q=\dfrac{\rho^2}{1-\rho}$
- 平均逗留时间 $W=\dfrac{1}{\mu-\lambda}$，平均等待时间 $W_q=\dfrac{\rho}{\mu-\lambda}$

**M/M/c 模型**：多服务台，$L_q=P_0\dfrac{\rho^c}{c!(1-\rho)}^2$（$P_0$ 为系统空闲概率）。**Little 定律**：$L=\lambda W$ 适用于任意稳定系统。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 服务设施 | 银行、收费站、超市 | 随机到达/服务 |
| 系统性能 | 网络、制造线 | 吞吐、等待 |
| 投资决策 | 增加服务台 | 成本-等待权衡 |

### 可视化图表类型

- 利用率 $\rho$ vs $L/W$ 曲线（排队指标）
- 服务台数 vs 平均等待时间（M/M/c）
- 模拟到达-服务事件序列

|---------|------|------|------|
| 运筹学（第4版）第11章 | 运筹学教材编写组 | 2012 | 清华大学出版社 |

```python
def mm1(lam, mu):
    rho = lam / mu
    return dict(L=rho/(1-rho), Lq=rho**2/(1-rho),
                W=1/(mu-lam), Wq=rho/(mu-lam))
```

### 算法选择指南

- 单服务台指数分布：M/M/1 公式直算。
- 多服务台：M/M/c（P0 数值求解）。
- 一般分布：排队模拟（06-综合蒙特卡洛）。

## 8. 存贮论

### 算法介绍

存贮论研究订购/生产批量与补货时点，使存贮总费用最小。**经济订购批量 EOQ**（需求率 $r$、每次订购费 $c_1$、单位存贮费 $c_2$）：

$$
Q^*=\sqrt{\frac{2c_1 r}{c_2}},\quad
\text{最小总费用 } C^*=\sqrt{2c_1c_2 r}
$$

**允许缺货**：引入单位缺货损失 $c_3$，批量与缺货量相应调整。**有数量折扣**：分段比较总费用曲线，取分段内最小值。**随机需求**：转向 7 概率模型（报童问题）与安全库存。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 库存管理 | 原材料、商品订购 | 确定性需求 |

```python
import numpy as np
def eoq(r, c1, c2):
    Q = np.sqrt(2*c1*r/c2)
    return Q, c1*r/Q + c2*Q/2   # 批量与最小费用
```

## 9. 对策论（博弈论基础）

### 算法介绍

对策论研究多个决策者利益冲突的决策。**矩阵对策**：局中人 I 有 $m$ 个策略、II 有 $n$ 个策略，支付矩阵 $A$（I 得 II 付）。

- **纯策略**：存在鞍点 $\max_i\min_j a_{ij}=\min_j\max_i a_{ij}=v$。
- **混合策略**：无鞍点时求最优混合概率。线性规划求解：

$$
\max v\quad \text{s.t. } \sum_i a_{ij}p_i\ge v,\ \sum_i p_i=1,\ p_i\ge0
$$

其解 $p^*$ 为 I 的最优混合策略，$v$ 为对策值。**合作博弈**（Shapley 值、核）用于收益分配。**纳什均衡**为一般非零和情形（见 06-综合资产博弈论条目）。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 对抗决策 | 军事、投标、定价 | 支付矩阵 |
| 收益分配 | 联盟合作 | Shapley 值 |
| 均衡分析 | 竞争市场 | 纳什均衡 |

### 可视化图表类型

- 支付矩阵热力图 + 鞍点标注
- 混合策略收益曲线（对 $p$ 扫描）
- 双人收益散点（均衡点）

### 代码实现要点

```python
import numpy as np
from scipy.optimize import linprog

def mixed_strategy(A):
    """I 的最优混合策略与对策值（A 为 I 的支付矩阵）"""
    m, n = A.shape
    A_ub = -A.T          # sum_i a_ij p_i >= v  <=>  -sum_i a_ij p_i + v <= 0
    b_ub = np.zeros(n)
    A_eq = np.ones((1, m+1)); A_eq[0, m] = 0
    b_eq = [1.0]
    c = np.zeros(m+1); c[m] = -1          # min -v => max v
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=[(0, None)]*m + [(None, None)])
    p = res.x[:m]
    return p, -res.fun                    # (混合策略, 对策值)
```

### 算法选择指南

- 有鞍点：纯策略直接判定。
- 无鞍点：混合策略 LP。
- 多主体非零和：纳什均衡/合作博弈（注意均衡唯一性说明）。
