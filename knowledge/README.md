## 四、怎么用（三步）

1. **建模时**：skill 自动通过 `references/算法索引.md` 路由到上述资产；想查经典模型看 08，运筹看 09，案例/MATLAB 模板看 10。
2. **查算法大全**：先在 `11-算法大全检索索引.md` 或 `算法大全_检索索引.md` 定位章节 → 读 `算法大全_全文/算法大全第XX章_*.txt` 精读；需要公式排版时打开 `原文PDF/算法大全第XX章_*.pdf`。
3. **找 MATLAB 程序**：`_m_programs/` 里有 14 讲配套的 194 个 `.m` 现成程序（按讲次+文件名可定位）。
4. **改内容**：改 `08/09/10` 这类新增资产时，Skill 本体与这里都要同步（md5 校验保证一致）。
