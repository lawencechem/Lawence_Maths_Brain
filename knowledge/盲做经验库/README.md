# 评阅要点库

每完成一道竞赛题，把"该题评阅要点 → 命中方法 → 结果对照"回写到这里。
陌生题先查本库 + 再检索当届官方要点，让 skill 越用越懂国赛评审。

## 条目模板（每题一个文件 `<年份>_<竞赛>_<题号>.md`）
- **参考区间**：各问参考答案/数值范围（来源注明：官方/同题论文/AI评审）
- **命中情况**：各问我们的结果 vs 参考，命中/偏低/超出
- **命中方法**：每条评阅要点 → 用什么方法命中（体判据/贪心/变量缩减/计算耗时等）
- **不足与对策**：偏低处 + 改进方法（供复现）

## 现状
- `2024_CUMCM_A.md`：2024 国赛 A 题（板凳龙）——盲做实测回写，无官方对标。
- `2024_CUMCM_B.md`：2024 国赛 B 题（生产过程中的决策问题）——盲做实测回写，无官方对标；含复现锚点。
- `2025_CUMCM_A.md`：2025 国赛 A 题（烟幕干扰弹投放策略）——参考区间来自用户 AI 评审，已记录命中与改进。
