# 盲做经验库

每完成一道竞赛题，把"题面拆解必答项 → 命中方法 → 自洽结果 → 不足与对策"回写到这里。
陌生题先查本库的题面拆解与可迁移方法；按本 Skill 全局盲做规则，**不检索官方评阅要点/参考答案/赛后解析/赛后同题论文**，库内不存任何官方/参考区间数值。

## 条目模板（每题一个文件 `<年份>_<竞赛>_<题号>.md`）
- **题面拆解**：各问目标/输出口径/约束/必答项（自题面，非官方要点）
- **自洽结果**：各问结果与复现锚点（无外部对标）
- **命中方法**：每条必答项 → 用什么方法命中（体判据/贪心/变量缩减/计算耗时等）
- **不足与对策**：可改进处 + 改进方法（供复现）

## 现状
- `2024_CUMCM_A.md`：2024 国赛 A 题（板凳龙）——盲做实测回写，无官方对标。
- `2024_CUMCM_B.md`：2024 国赛 B 题（生产过程中的决策问题）——盲做实测回写，无官方对标；含复现锚点。
- `2025_CUMCM_A.md`：2025 国赛 A 题（烟幕干扰弹投放策略）——盲做默认前的历史条目，参考数值已作废，仅保留题面拆解与方法记录。
