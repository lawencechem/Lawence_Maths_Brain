# 建模设计理论

## 问题与模型匹配

| 问题结构 | 模型方向 | 必查条件 |
|---|---|---|
| 约束下求最优 | 线性、整数、非线性、鲁棒或多目标优化 | 变量类型、可行域、目标和约束 |
| 随时间变化 | 时间序列、状态空间、机器学习预测 | 时间顺序、平稳性、外生变量和回测 |
| 多指标排序 | 统计降维、组合赋权、效率评价 | 指标方向、相关性、权重依据和稳健性 |
| 网络关系 | 最短路、网络流、复杂网络 | 节点、边、方向、权重和连通性 |
| 不确定系统 | 概率模型、蒙特卡洛、随机或鲁棒优化 | 分布依据、场景和风险指标 |
| 模式识别 | 聚类、分类、集成学习 | 标签、样本代表性、数据泄漏和验证集 |

## 设计原则

1. **充分性**：覆盖题目目标、关键约束和关键数据。
2. **可证伪性**：预先定义会让模型失败的检验。
3. **可实现性**：公式、算法与 Python/MATLAB 工具一致。
4. **可追溯性**：参数、阈值和假设都有来源。
5. **创新性**：避免直接套用常见简单模型；创新点必须能映射到具体实现和验证。

复杂度由问题结构、数据和验证要求决定。

## 控制与策略题的决策空间

对设计、调整、调度、增加组件或多主体协同问题，模型选择前必须读取 `../../innovation-special/references/决策空间完备性.md`。不能只枚举幅值和阈值；须分别核对量值、时序、结构、信息四类自由度，并把领域对象之间的关系映射为决策、状态、约束、外生量或有依据的不适用项。

凡用 `n×单体`、求和、平均、同步、代表性个体、固定顺序或固定拓扑简化多个对象，先把它记录为基线假设，再构造最小替代表示。是否采用替代表示由同口径原型、解析尺度、可辨识性或硬约束决定，不能因为基线已经写成聚合公式就把该关系误认成题面硬约束。

## 模型数量

每道子问题最多两个独立模型体系。允许：

- 一个主模型；
- 主模型加一个对比或验证模型；
- 两个串联模型分别完成必要阶段。

灵敏度分析、残差分析、消融实验、交叉验证和可视化属于验证方法，不单独计作模型。

物理问题按模型族而不是公式版本计数。同一物理机制、同一组核心状态变量和控制方程，在不同近似阶次、反射次数、边界简化或数值精度下的表达，属于一个模型族。例如，两光束干涉与多光束干涉若只是同一干涉机制的精度展开，计为一个模型；若引入不同传播机理或新的耦合状态方程，才另计模型。

**退化自洽句（模型族硬性要求）**：凡含基础版与扩展版的模型族，扩展版必须含显式退化语句，格式固定：
`当 [参数] → [极限] 时，式(X)退化为式(Y)，因此高阶模型自然包含低阶模型。`
缺该句 → 该模型族未通过建模自审，视为未完成。退化方向必须真实可执行（把参数取极限能回到低阶式），禁止用话术冒充包含关系。

两个模型得到相近结论并不构成删除理由。应根据研究目的、方法差异和证据价值决定是否保留。

## 组合方式

| 方式 | 条件 | 示例 |
|---|---|---|
| 串联 | 前一模型输出是后一模型必要输入 | 需求预测 → 库存优化 |
| 并行 | 需要比较不同假设或方法 | 统计模型与机器学习模型回测 |
| 主模型加验证 | 一个模型回答问题，另一模型验证边界 | 优化模型 + 仿真验证 |

## 验证设计

验证方式根据模型选择，可包括留出集、滚动回测、残差诊断、约束可行性、最优性界、稳定性、灵敏度、消融实验和外部数据对照。检验阈值必须写明依据。

## 模型—文献一致性（本地 P9，挂 M1）

对驱动核心结论的模型、常数、经验关系和数据窗口建立“模型适用性表”，至少含：来源与年份、材料/对象、状态或工况、变量范围、测量定义、参数来源、外推项、拟用数据窗口、采用或拒绝理由。

1. **来源与参数分开核验**：模型形式要有理论或实验依据；关键参数优先使用与题目对象和工况匹配的权威来源。由本题数据估计的参数必须写明估计方法，并标注“由数据反演，无独立锚点”，不能把同一数据反演值再伪装成独立文献验证。
2. **适用域核验**：逐项比较文献适用域与题目数据域。超出范围时标为外推，并设计对外推敏感的验证；“引用过某篇文献”不等于模型适用。
3. **窗口冻结**：在最终答案出现前，依据文献适用域、仪器有效范围、饱和/缺失、信噪比和可观测特征等与目标答案独立的标准，冻结主分析窗口与排除规则。保留候选窗口对照表（窗口 / 纳入状态 / 独立依据 / 版本时间）。
4. **事后差异**：看到结果后才改变窗口时，必须标为事后探索，完整报告原窗口与新窗口结果及变更原因；不得只保留更接近期望值的窗口。多窗口结论不一致且无法解释时，报告模型形式不确定性或可辨识区间，不强行给唯一点估计。

## 自由参数伦理（本地 P10，挂 P2）

凡引入无直接文献/物理来源的自由参数（如 n₀ 等被用来压残差）时，必须通过四问，任一不过则该参数不得进模型，论文如实写局限：

1. **物理意义**：该参数代表什么物理量，处于什么预期范围？
2. **净贡献**：无它时残差多少、加了减多少——减少量必须超过噪声底 2σ（默认阈值，可被题目精度/预判摘要覆盖，覆盖记理由）；连 2σ 都过不了，参数只是拟合自由度的装饰。
3. **能否被更底层物理假设解释**：残差能否用偏振、衬底 ε∞、界面粗糙度等更底层物理假设解释？能 → 优先解释，不先加自由参数。
4. **是否与现有参数退化**：新参数与既有参数（如 nd 耦合）是否退化？退化 → 辨识性失败，参数不可单独标定。

**守卫条款（总闸优先）**：本小节所有数值阈值为默认值，可被题目精度/预判摘要覆盖。若数据呈现结构矛盾信号（谷位差、突变沿、非正弦干涉等），「加参数未过 2σ」不得成为跳过高阶模型解释的依据——高阶必须尝试，失败走分歧报告；奥卡姆简化只适用于无结构矛盾的情形。
