# 解析与结构降维检查

解析降维是候选创新来源，不是所有优化题的第一动作。只有问题存在可利用的数学结构时才采用，并证明等价性或量化误差。

## 触发信号

- 目标或约束具有单调性、凸性、对称性、守恒量或齐次性。
- 部分变量可由等式约束、KKT 条件、几何关系或充分统计量恢复。
- 候选之间存在支配关系、冗余状态或不可达区域。
- 网络、时序或空间关系具有稀疏、局部、分块或可分结构。
- 原求解规模、稳定性或解释性确实构成瓶颈。

变量数量本身不能证明贪心、筛选或降维合理。

## 检查步骤

1. 明确要保持的可行性、目标值、最优解、决策判定或安全边界。
2. 给出消元、映射、分解或筛选规则的数学依据。
3. 将候选分类为精确等价、保守内外逼近或可控近似。
4. 对精确方法证明双向映射；对保守方法证明包含关系；对近似方法给出误差界。
5. 与未降维基线在可计算小实例上逐项核对，并测试最可能失效的边界。
6. 只有真实计算证明其改善规模、耗时、稳定性或解释性时，才升级为创新。

## 常见模式

| 结构 | 可能方法 | 必要证明 |
|---|---|---|
| 等式约束 | 变量消元 | 可行域双向对应 |
| 对称或守恒 | 商空间、基本单元、状态恢复 | 保持目标和约束 |
| 单调性或支配 | 固定变量、剪枝 | 被删区域不含更优解 |
| 几何相切或临界 | 解析边界、低维参数化 | 临界条件和适用范围 |
| 网络可分性 | 分块、消息传递、分解协调 | 接口变量和一致性 |
| 近似降阶 | 代理或低阶模型 | 误差界和高保真对照 |

论文只报告实际证明和量化结果，不使用固定“降至二维”“命中率显著提升”等模板话术。
