# 评阅要点前置

目标：在建模前确认当届官方必须回答的内容和评价口径，不把往届范文、参考数值或历史高分方法变成调参目标和创新模板。

## 步骤

1. 从目标竞赛官方网站或可追溯发布页查找当届规则、题目说明和评阅要点。
2. 把每条官方要点映射为“必须回答的结论、所需证据、建议章节”。
3. 将来源 URL、适用届次和核验日期写入内部检查；没有官方来源时明确标记为待核验。
4. 同题论文和往届结果只用于发现口径差异、常见错误和数量级风险，不作为必须达到的答案。
5. 历史案例中的算法、图表和创新只能作为候选，必须重新通过本题机制、实现和证据门控。

## 结果异常核查

结果与参考区间不同时，依次检查指标口径、单位、数据版本、约束、边界、随机性和模型假设。代码与模型合同成立时如实解释差异，不修改数据、评价口径、约束、种子或模型以追逐范文数值。

参考答案不能证明当前模型正确；接近参考答案也不能替代复现、可行性和误差检查。
