# 建模手质检清单

- [ ] 已读完题目和全部附件，输入文件保持只读。
- [ ] 先完成题目理解，再写结论目标和模型方案。
- [ ] 每个子问题已声明 `completion_mode` 与判断依据；含开放优化或多目标权衡的题没有因首个可行解而误标为达标型。
- [ ] 每个竞赛型子问题已区分硬约束与软目标，写明目标优先关系、内部标尺、预期瓶颈、挑战预算和分配依据。
- [ ] 每道子问题最多两个独立模型体系；物理题的不同近似已按模型族计数。
- [ ] 每个变量、参数、单位、目标函数和约束定义完整。
- [ ] 数据判定标准有题目、官方、文献或分析依据。
- [ ] 已建立领域表示、数学表示和机制缺口；创新沙盒候选均标记为 `HYPOTHESIS`，没有预写提升数值或已验证语气。
- [ ] 创新候选覆盖有意义的简化、重构或增强方向，不按算法、图表或每问数量凑数。
- [ ] 竞赛型候选已标记 `competitive_relevance` 与原型成本；预算内高价值候选不会无证据直接淘汰。
- [ ] 物理几何简化已明确保持性质、证明等级、尺度或误差计划、反例和失效条件。
- [ ] 模型能由 Python 或 MATLAB 实现，依赖明确。
- [ ] 每个子问题已判断是否存在视觉论证缺口；候选图均写清读者疑问、核心主张、证据来源、建议载体和章节落点，没有按题号或图型机械列图。
- [ ] 非数据图的对象、变量、关系和箭头均能映射到模型定义；未生成通用“输入→模型→结果”流程图需求。
- [ ] 验证方法与结论风险匹配，失败条件和回退路线明确。
- [ ] 文献可追溯到 DOI 或原始出版页面。
- [ ] 关键模型与参数已做文献锚定：有赛前权威文献标准值，或无值时显式声明「由数据反演，无独立依据」（本地 P9）。
- [ ] 已声明适用波段与文献适用范围的一致性；超出文献覆盖的波段已注明外推（本地 P9）。
- [ ] 候选窗与失效窗已预先承诺：失效窗写明「不参与主结果」，附候选窗对照表，禁止按结果反选（本地 P9）。
- [ ] 只交付 `题目分析报告.md` 和 `术语表格.md`。
- [ ] 两个文件写入 `PROJECT_ROOT`，未覆盖 `SKILL_ROOT`。
- [ ] 作者自检完成后已由未参与编写的质检 Subagent 执行 `M1`，回执为 `PASS`。
- [ ] `M1` 通过后两个产物未发生未经复验的实质变化。
