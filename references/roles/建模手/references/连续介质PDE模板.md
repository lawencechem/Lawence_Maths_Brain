# 连续介质 PDE 快速建模模板

近 10 年 A 题中 ≥5 年涉及 PDE/连续介质物理（2023A 光热、2020A 炉温、2019A 油管、2018A 高温服装、2017A CT 反演）。
遇到连续物理过程（传热、传质、波动、扩散、反演）时按本模板快速上手。

## 何时用
连续介质随空间/时间分布、需建立偏微分方程描述、边界/初始条件给定或可假设。

## 常用 PDE 基本形式（无量纲/量纲化后）
| 物理过程 | 方程 | 适用赛题例 |
|---|---|---|
| 热传导（抛物型） | $\dfrac{\partial T}{\partial t}=\alpha\nabla^2 T + Q$ | 炉温曲线、高温服装 |
| 波动（双曲型） | $\dfrac{\partial^2 u}{\partial t^2}=c^2\nabla^2 u$ | 声波、振动 |
| 对流扩散 | $\dfrac{\partial C}{\partial t}=D\nabla^2 C - \mathbf{v}\cdot\nabla C + S$ | 污染扩散、烟云扩散 |
| 稳态（椭圆型） | $\nabla^2 u = f$（Poisson）/ $=0$（Laplace） | 温度分布、静电 |
| 反问题/CT | Radon 变换 / 层析反演 | CT 成像 |

## 建模四步
1. **守恒律起手**：对微元写"积累 = 流入 − 流出 + 源"（质量/能量守恒），导出方程。
2. **定解条件**：边界（Dirichlet/Neumann/第三类/对流换热）+ 初始条件；题目给什么用什么，缺的显式假设。
3. **量纲/无量纲化**：先量纲核验，必要时无量纲化减小参数空间。
4. **可观测对齐**：方程/解要与题目给的数据（温度点、流量、图像）对应，用于参数辨识与验证。

## 数值求解骨架（一维热传导，有限差分）
```python
import numpy as np
# u_t = alpha u_xx, x in [0,L], t in [0,T]
L, T, alpha = 1.0, 0.1, 0.01
Nx, Nt = 200, 20000
dx, dt = L/(Nx-1), T/Nt
r = alpha*dt/dx**2            # 稳定条件 r<0.5
u = np.zeros(Nx)
u[0]=u[-1]=0.0                # Dirichlet 边界
for n in range(Nt):
    u[1:-1] += r*(u[2:]-2*u[1:-1]+u[:-2])   # 显式格式
    # 输出/记录关键时刻解
```
- 显式格式稳定条件 r=αΔt/Δx²<0.5；隐式（Crank–Nicolson）无条件稳定但需解三对角。
- 高维/复杂域用 `scipy`（`solve_ivp` 离散后）、FEM 库（`FEniCS`/`deal.II`）或 `pde` 库按需选用。

## 验证
- 与解析解/稳态极限对比；网格收敛性（Δx→0 结果趋稳）；能量/质量守恒检查。
- 参数辨识：解与实测数据的最小二乘拟合，报告误差与不确定度。
