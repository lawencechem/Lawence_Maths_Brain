# 题面拆解与必答清单前置（盲做）

目标：在建模前从题面自身拆解必须回答的内容，不检索官方评阅要点、参考答案或赛后解析，不把往届范文、参考数值或历史高分方法变成调参目标和创新模板。

## 默认盲做

- 全程按“实时参赛”处理：**禁止检索官方评阅要点、参考答案、赛后解析及赛后发表的同题论文**；文献依据只用竞赛年及更早的公开文献。
- “官方规则”仅指当届规则、题目说明、模板、篇幅和提交格式等硬性要求（与评分无关的部分），不包含评分要点。
- 官方规则可从官方网站或可追溯发布页核验；评分要点不在此列。

## 步骤

1. 从官方可追溯发布页获取当届规则、题目说明和模板（仅硬性提交要求，不含评分要点）；没有官方来源时明确标记为待核验。
2. 逐条拆解题面：每问的目标、输入/输出口径、约束、数据来源和必须回答的结论。
3. 把每条必答项映射为“必须回答的结论、所需证据、建议章节”。
4. 从 `../../../../knowledge/盲做经验库/` 读取历史条目的题面拆解与可迁移方法（只读，不读取其中任何官方/参考区间数值）。
5. 历史案例中的算法、图表和创新只能作为候选，必须重新通过本题机制、实现和证据门控。

## 结果自洽性检查

结果只做自洽性/复现性/量纲一致性核查：依次检查指标口径、单位、数据版本、约束、边界、随机性和模型假设。代码与模型合同成立时如实记录结果；没有外部参考区间可对标，不修改数据、评价口径、约束、种子或模型去追逐任何范文数值。

接近任何网传数值都不能替代复现、可行性和误差检查。
