# 参考文献规范（CUMCM）

## 一级原则：中文核心优先
引用优先级：**中文核心 ＞ SCI / 算法原始文献 / 权威教材与国标、行业标准 ＞ 低质 OA（不入参考文献，仅正文文字对照）**。
文献来源不限于期刊论文：中文权威教材（如光学、数理、控制类教材）与国家/行业标准（GB/T 等）与论文同属可追溯权威文献，均可列入参考文献。
检索顺序：先查中文核心，再补国际文献。
默认盲做：**不检索官方评阅要点/参考答案/赛后解析/赛后同题论文**；文献只用竞赛年及更早的公开文献。
适用核心刊：《兵工学报》《红外与激光工程》《电光与控制》《控制与决策》等军工/优化类。

## 要点
1. **低质 OA 同题文献不列入参考文献**。确需数值对照时，保留在正文文字（表述为"据近年公开的同题研究报道"），
   取消上角标引用；不要赌评委不细看（申报国一必细读全文与参考文献）。
2. 基础公式不引顶会论文（点到线段距离引计算几何教材，不引 SIGGRAPH）；复杂算法引原始文献或权威教材。公式、参数或阈值出自国家/行业标准（如 GB/T …）时直接引该标准；基础公式也可引权威中文教材（如光学、数理、控制类教材）。
3. 中文文献 GB/T 7714-2015；英文刊名斜体。国家标准/行业标准按 GB/T 7714-2015 著录：标准编号 + 空格 + 标准名称 + `[S]`，如 `GB/T 42905-2023 空间飞行器轨道测量术语[S].`（编号与名称以官方发布为准，不编造）。
4. 每条 DOI 用 OpenAlex works API 核验。**国内期刊论文在 OpenAlex 返回 404/无记录时不直接判失败**（OpenAlex 对国内核心期刊收录不完整），改由知网/期刊官网核验题录（题名、作者、年卷期页），核验通过即视为可追溯、可列入参考文献；只有公开渠道（OpenAlex、期刊官网、知网）均无法核验时才标 `BLOCKED`，禁编造题录。
5. 正文引用与文末条目双向对应（paper_format validate 检查）。
6. **引用须"确有所指"**：每条引用的实际内容必须支撑其所在句的具体主张，点明对应关系（如"以半径近似遮蔽，物理依据是烟幕透过率衰减[1]"）；禁止把主题相关但不直接支撑的文献"参见式"堆在一处。
7. **引用时效性**：引用论文的发表年份必须 **≤ 目标竞赛年份**（如 2025 年竞赛只能引 ≤2025 年已发表文献）。竞赛年之后发表的文献**不得入参考文献**；其数值/结论若确有价值，只能作无引用的正文叙述且不得暗示来源（"据近年公开报道"会穿帮）。检索/选文时先核对年份，超年的候选直接剔除。

## 参考结构（8–10 条）
中文核心 2–3 + 同题对照 1（须为竞赛年及更早，为赛前公开文献而非赛后解析）+ 算法原始 2 + 权威教材/经典教材 2 + 国标/行业标准 0–1 + 匹配教材 1–2。

## 中文核心检索
见 `tools/paper_search/SKILL.md` 中文核心检索节：双引擎 → OpenAlex 核 DOI（国内期刊 OpenAlex 404 不算失败，改由期刊官网/知网核验题录）→ 仅公开渠道均不可核验时给用户知网检索式、导出 GB/T 7714 题录。
