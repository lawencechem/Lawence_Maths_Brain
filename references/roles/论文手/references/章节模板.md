# 论文章节模板

章节名称和顺序首先服从当届官方模板。官方没有固定章节时，可按题目内容使用以下逻辑结构，而不是机械套用所有章节：

1. 标题与摘要页
2. 问题重述与问题分析
3. 模型假设与符号说明
4. 各子问题的模型建立、求解、验证和结果
5. 灵敏度、稳健性或误差分析
6. 模型评价与适用边界
7. 参考文献
8. 官方允许或要求的附录

## 摘要

摘要应直接回答：解决了什么问题、采用什么模型、得到哪些实际数值结果、如何验证、结论适用于什么条件。篇幅、关键词、摘要页和编号完全按当届官方规则。

## 问题重述与分析

用自己的语言说明任务、输入、约束和输出，不能虚构背景数据。问题分析应解释为何选择当前模型以及模型如何对应题目结构。

## 模型建立与求解

每个子问题最多两个独立模型体系；同一物理机制的基础近似和高精度展开按一个模型族组织。按“变量与参数 → 假设依据 → 数学定义 → 算法 → 运行参数 → 实际结果 → 验证”展开。模型选择以题目适配和证据为准。

### 章节叙事默认弧（本地 P6，数字门控）

每个核心问题的求解章节，默认按「冲突 → 探究 → 解决」三段式展开：

- **冲突**：基础模型拟合数据时在哪里失效、残差多大（必须给出 RMSE 或残差结构）。
- **探究**：引入量化判据（如 ρ、F、AIC 差、SPRT 边界），证明失效原因（必须给出判据数值与阈值比较）。
- **解决**：完成下列三项中的**至少两项**，并给出最终结果（必须给出回收偏差 Δd 区间）。**所有阈值由题目/材料物理预期确定，写入第10节预判摘要，不在此写死**：
  1. **异常特征数值复现**：高阶模型复现物理特征（谷位差、谷宽、角度偏移等，≥2 个特征；阈值见预判摘要）。
  2. **模型比较统计判据**：ΔAIC 或 RMSE 改善超过预判摘要设定的阈值。
  3. **外部锚点对照**：与赛前文献/国标参考值相对差在预判摘要设定的范围内（无锚点时注明无参考）。

**硬性门控**：每一幕至少包含一个真实且可复核的数值（如 RMSE=8.3%、ρ=0.30、Δd=+29~+471 nm）。**无数值支撑的幕自动折叠，不允许单独成节。** 偏离此默认弧时，须在证据大纲（`W1`）中注明理由。

**总闸切换**：若判据指向物理矛盾且无法闭环，则不存在"解决"幕，自动输出「分歧报告」幕——同时报告各口径数值、差异 X%、为何无物理依据选择其一，给出不确定区间；这是完整完成形态，不是未完成。

## 结果分析

每个主张紧跟真实表格、图或数值输出。置信区间、p 值、误差和改进幅度都由代码计算，并与复现清单一致。

## 模型评价

说明优点、局限、失败条件和可推广范围。局限必须来自假设、数据、算法或验证结果。

## 参考文献

正文引用与文末条目双向对应。作者、题名、年份、来源、卷期页和 DOI 以原始出版页面为准；双引擎搜索只用于发现和交叉核验。
