# 论文自审框架

本清单是论文手的作者自检，不替代 `W1`、`W2` 独立 Subagent 验收。

## M0 · 概念可复核性（最高优先级门禁）

对论文每个关键数值，作者必须能在**三句话内**说清「从附件原始行到该值的完整路径」（原始字段 → 处理/变换 → 公式 → 数值）。

- 说不清路径的数值视为拷贝，**禁止**进入论文。
- 摘要、结果表、误差区间里的每个数字都须经得起这条追问；编程手在 `results/复现清单.json` 里留好从数据到数值的入口。
- 本门禁对全文生效，先于其他任何检查项。

### M0-1 · 外部合理性门禁（外部锚点 · 判定权在证据）

M0 之后、官方规则之前，对每个关键数值追加外部合理性核对。**偏差来源与"偏差是否可接受"由证据是否闭环决定，不由算法脚本裁决，也不等用户**：

- **预期范围对照**：结果必须落在材料/物理预期范围内（预期范围由题目/材料物理预期确定，写入第10节预判摘要）。落在范围外 → 不得作为点估计输出，切换分歧报告模式给出区间。
- **锚点相对差**：有赛前/国标参考值时计算相对差；超过预判摘要设定的阈值（写入第10节，不在此写死）时，归因审计是**证据链**（≥2 种量化解释，各带证据与局限），不是"脚本对比后输出通过"。归因无法量化 → 结论加「在该折射率口径下」限定语，并以分歧报告表述，不提供带内唯一点估计。
- **无锚点**：只做预期范围对照，注明「无参考」，并以分歧报告表述；禁止以「无对标」为由省略本门禁或输出点估计。
- 与 `P5` 可辨识带联动：合理性未过或归因失败 → 报告为「未解之谜」/「分歧带」，不输出单一主结论。

## 一、官方规则

- [ ] 已记录目标竞赛、届次、官方规则和官方模板来源。
- [ ] 页面、摘要页、编号、页数、字体、提交格式等逐项符合当届官方文件。
- [ ] 未把本 Skill 默认值或往届经验写成官方规定。

## 二、内容与证据

- [ ] 长篇正文前的证据大纲已由独立质检 Subagent 执行 `W1` 并返回 `PASS`。
- [ ] 每个结论都有真实代码结果、图表、公式或文献支撑。
- [ ] 创新证据清单已通过审计；论文只把 `ADOPTED` 项称为创新，允许没有核心创新。
- [ ] 摘要中的数值与正文、表格、图和复现清单一致。
- [ ] 每道子问题最多两个独立模型体系；物理模型的不同近似按模型族说明清楚。
- [ ] 没有虚构背景数据或未核验引用。
- [ ] 局限和适用边界具体、可追溯。

### 不确定度与模型局限写法（本地 P5 + P8）

- **系统偏差写法（P5）**：当不同假设/口径给出不一致但都可信的结果时，**禁止强行平均**、**禁止用均值±标准差假装收敛**，必须报告「模型可辨识带」[d_min, d_max]，并说明带宽由何种系统偏差主导（如「衬底界面相位色散」）。报告中缺少可辨识带 → 判定「未通过自审」。
- **未解之谜写法（P8）**：若升级验证失败或边际收益不足以证明新增复杂度，必须输出固定句式段落：
  `本模型在[具体位置]发现[具体异常]，经[判据]检验后未能归因于[候选机制]，该异常作为模型局限如实报告。`
  缺少此段时视为刻意隐瞒模型局限，**一票否决**。承认未知即为有效结论；禁止为掩盖未归因异常而滑动窗口或剔除数据。

## 三、文档结构

- [ ] Word 分支的公式是可编辑 OMML；用户显式要求 LaTeX 时，LaTeX 分支的公式是可编译源码。无公式截图。
- [ ] 同时生成两种格式时，Word 与 LaTeX 的正文、数据、图表、公式和结论一致。
- [ ] 已分别核对 PDF 总页数、正文起始页、附录起始页和正文页数；官方正文上限未错误计入摘要或附录，官方硬约束和非官方质量目标已明确区分。
- [ ] 图数由主张—证据映射决定，没有为满足固定数量或图型多样性生成无论证价值的图。
- [ ] 每个子问题至少有 1 个正式证据单元支撑关键结论，图、表、关键公式组或经核验文献均可；没有把全部视觉证据集中在问题一或单一子问题。
- [ ] 每幅 `KEEP` 图都有图前引入、图后观察与推论，位置靠近对应推导、算法或验证；图表论证清单中不存在 `PENDING_RENDER`。
- [ ] 表格可编辑，每幅图和每个表都有连续编号、题注及正文引用，没有孤儿图表。
- [ ] 参考文献与正文引用双向对应，DOI 和出版信息已核验。
- [ ] 不含 `[待补充]`、模板示例正文或临时占位符。

## 三点五、评分导向自检（复杂题必做，见 `评分导向自检.md`；盲做口径：不检索官方评阅要点/参考答案/赛后解析）

- [ ] 验证和边界测试由结论风险触发，覆盖最可能改变可行性、排序或安全性的情形。
- [ ] 采样、网格、随机算法或灵敏度只在模型需要时出现，阈值具有题目或数值依据。
- [ ] 物理几何简化有保持性质、证明或误差界，图没有代替证明。
- [ ] 每个 `ADOPTED` 创新具有实现或证明、合理基线、量化结果和失效边界；没有强制配图和重复话术。
- [ ] 参考文献含中文核心、零低质 OA。
- [ ] 图表 300DPI/SVG、编号与正文引用连续。
