# 评分导向自检

目标：把题目完成度、模型正确性、证据可信度、真实创造性和表达清晰度映射到论文，而不是用算法、图表和灵敏度数量制造“加分项”。

## 六维检查

| 维度 | 检查重点 | 论文章节 |
|---|---|---|
| 问题分析 | 目标、约束、数据和输出口径完整，假设有依据 | 问题分析、假设 |
| 模型建立 | 关键机制进入状态、目标和约束；简化有证明或误差 | 模型建立 |
| 求解 | 方法与数学性质匹配；有必要的最优性、残差或稳定性证据 | 求解与验证 |
| 结果 | 回答每个子问题，数值、单位、方案和边界可追溯 | 结果分析 |
| 创新 | 仅 `ADOPTED` 项进入创新表述，机制和量化证据真实 | 摘要、方法、结果 |
| 写作 | 主张克制，图表和公式承担明确证据任务 | 全文 |

## W2 前自检

- [ ] 必答项来自题面拆解，未检索官方评阅要点/参考答案/赛后解析/赛后同题论文；没有把任何参考数值当成调参目标。
- [ ] 结果存在自洽性/复现性/边界差异时已核对口径、单位、约束、数据和假设，并如实解释。
- [ ] 验证方式由模型风险触发，没有机械添加网格、蒙特卡洛、双参数灵敏度或多求解器。
- [ ] 启发式或非凸求解若存在局部最优风险，已有小规模精确解、上下界、多起点或公平预算对照之一。
- [ ] 完全枚举、闭式解和有最优性证书的模型没有为了显得复杂而添加异构求解器。
- [ ] 物理或几何简化说明了保持性质、证明等级、尺度依据、误差或保守方向以及失效条件。
- [ ] `results/创新证据清单.json` 已通过审计；所有正文创新来自 `ADOPTED`，允许没有核心创新。
- [ ] 存在竞赛型子问题时，竞争性搜索账本已通过审计；首个可行解没有被包装成最终竞争结论。
- [ ] 只有具备 `PROVEN_OPTIMAL` 停止证书的结果使用“最优”；其余明确为当前最好已知方案并报告 gap 或未知前沿。
- [ ] 每项创新绑定最直接的证据单元，不强制配图、固定三段话术或固定展示次数。
- [ ] 摘要没有出现代码和结果中不存在的蒙特卡洛、阻尼、交叉校验、显著提升或稳健结论。
- [ ] 参考文献确有所指、元数据可追溯；图表编号、引用和输出质量合格。
- [ ] 假设与引证已按三档标注（逐字支撑/结构推导/建模选择），引句确实支撑所引主张；先验阈值未把数据先验写成模型能力（`终审清单.md` B1/B2）。
- [ ] 确定性终审 lint（数字↔`results` 同源、占位符、双重编号、关键口径锚点）已运行且 0 命中或全部解释；每个定性结论都有数字锚点（`终审清单.md` A/B3）。

缺项返回对应角色修正，不以宣传性文字替代代码、证明或结果。
