# 侦探协议（决策回路核心协议）

> ⚠️ **本文件为人类可读章程，不参与执行链路。** 执行规则已以分布式补丁落入各角色工作流文件（分布位置索引见文末）；修改本文件不影响任何执行，勿据此推断行为。要改行为，改对应角色的本地补丁。
>
> 定位：本协议规定建模全流程的**决策回路**——当什么信号出现时，必须想什么、做什么、出示什么。它不是内容模板，不制造普适输出强制：每条原则都有明确的触发条件。
> 语法约定：与 Skill 其余部分一致——「禁止/必须/视为未完成」为硬约束；所有数值为**默认阈值**，被题目精度、官方规则或实测噪声覆盖时必须记录理由。

## P0 · 反幻想（空假设优先）
- 触发：任何偏离预期形态的数据点/区间（深谷、尖峰、突变沿）。
- 门控：异常偏离 < **3σ**（局部噪声底标准差，取异常点邻域残差，必须在代码中可复现）→ 判定「统计不显著」，**禁止**触发任何升级流程，按噪声处理并记录阈值与数量。
- 依据：工程 3σ 原则；σ 不得口头估计。
- 通过 3σ 门控后，才进入 P1。

## P1 · 异常即线索（先归因，后动作）
- 任何偏离预期形态的数据点/区间，**必须先归因，后动作**。
- 归因分叉：
  - (a) 随机噪声 / 标定截断 / 口径伪迹 → 允许剔除或平滑，**必须**记录阈值、数量与依据；
  - (b) 高阶机制签名（反射率深谷、尖峰、非正弦条纹、突变沿）→ **禁止**剔除、**禁止**滑动窗口避开，**必须**触发模型升级流程。
- 未完成归因的异常不允许被「处理」。

## P2 · 低阶已死自证
- 触发：写「因此必须采用高阶模型/升级模型」类因果句**之前**。
- **必须**出示低阶模型失败的量化证据（任一）：
  - 低阶拟合残差 RMSE > **2σ**（噪声底）；或
  - 残差在异常区呈系统结构（非随机分布）。
- 无证据 → **禁止**输出该因果句，该主张降级为「推测」。

## P3 · 退化自洽句
- 任何模型族必须含显式退化语句，格式固定：
  `当 [参数] → [极限] 时，式(X)退化为式(Y)，因此高阶模型自然包含低阶模型。`
- 缺句 → 该模型族未通过建模自审，视为未完成。

## P4 · 合成数据回收检验
- 触发（可量化，不依赖主观判断）：
  **两种独立口径/假设给出同一量的两个估计 d1、d2，且 |d1−d2| > 2√(SEM1²+SEM2²)**（差异超过联合标准误的 2 倍）时，强制触发本检验。
  - 凡参数反演/估计且驱动核心结论的，虽无口径分歧也建议执行（建议级，非强制）。
- 三明治架构（脚本：`编程手/scripts/synthetic_recovery.py`）：
  正向生成（高阶模型 + 已知真值 d_true）→ 加噪注入（实测噪声水平，默认峰值信噪比 50 dB，保证特征高出噪声底 ≥ 3σ）→ 反向回收（主方法反推）→ 报 Δd = d_recovered − d_true。
- 判定：|Δd| < 最终报告不确定度的 **1/3** → 可宣称「该方法在该工况下无偏」；否则**必须**修正方法或披露系统偏差。
- 报告必须给出 Δd 的数值区间（如 +29~+471 nm），禁止只写「通过/未通过」。

## P5 · 系统偏差用可辨识带表达
- 触发：不同假设/口径给出不一致但都可信的结果（即 P4 触发条件）。
- **禁止**强行平均、**禁止**用均值±标准差假装收敛。
- **必须**报告「模型可辨识带」[d_min, d_max]，说明带宽由何种系统偏差主导；建议附误差来源瀑布图（随机/系统/离散三分量）。
- 触发后未做 P4 回收的，P5 带宽不得声称可靠。

## P6 · 侦探弧（默认叙事，数字门控）
- 每个核心问题的求解章节默认按三段式展开：**冲突 → 探究 → 解决**。
- 每一幕**必须**至少含一个真实且可复核的数值（如 RMSE=8.3%、ρ=0.30、谷位差 0.04 cm⁻¹、Δd=−29 nm）。
- **无数值支撑的幕自动折叠，不允许单独成节。**
- 弧是默认形态，允许证据驱动偏离；偏离须在证据大纲中注明理由。

## P7 · 机制结论 · 四重锁定
- 任何「机制 X 显著」的结论，必须同时满足四重锁定：
  1. **矛盾锁定**：低阶模型失败数值（RMSE / 残差结构）；
  2. **判据锁定**：判据量超过阈值（默认 ρ>0.1、F>1，可被题目精度覆盖）；
  3. **复现锁定**：高阶模型复现异常特征（默认谷位差 < 0.5 cm⁻¹，阈值可覆盖）；
  4. **来源锁定**：机制能落到教科书级物理或盲做允许的赛前文献（菲涅耳、Airy、Drude 等），禁止自造机制冒充。
- 缺任一锁 → 该主张降级为「推测」。

## P8 · 停止条件 · 未解之谜
- 触发：升级验证失败，或边际收益不足以证明新增复杂度。
- **必须**输出固定句式「未解之谜」段落：
  `本模型在[具体位置]发现[具体异常]，经[判据]检验后未能归因于[候选机制]，该异常作为模型局限如实报告。`
- 承认未知即为有效结论；**禁止**为掩盖未归因异常而滑动窗口或剔除数据。

## M0 · 概念可复核性（最高优先级）
- 对论文每个关键数值，建模手必须能在**三句话内**说清「从附件原始行到该值的完整路径」（原始字段 → 处理/变换 → 公式 → 数值）。
- 说不清路径的数值视为拷贝，**禁止**进入论文。
- 落点：论文手 `自审框架.md` 顶部，作为 M0 门禁（集成时置顶）。
